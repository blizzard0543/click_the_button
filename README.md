# click_the_button

專案規格書：互動式網頁「Click the Button」
1. 專案概述

專案名稱：Click the Button

專案目標：建立一單頁式互動網頁。透過滑鼠與按鈕之間的距離與游標狀態，創造出「敵進我退，敵不動我偷偷靠近」的趣味互動體驗。

目標受眾：尋求趣味小遊戲、網頁互動彩蛋的網路使用者。

2. 核心功能需求 

網頁核心為一個 DOM 元素（按鈕），具有以下三種主要狀態：

2.1 逃離模式

觸發條件：當使用者的滑鼠游標距離按鈕邊緣小於設定的「警戒距離」（例如：100px）時觸發。

行為邏輯：

按鈕會根據滑鼠靠近的方向，往反方向（或帶有隨機偏移的角度）快速移動。

邊界防護：按鈕在逃跑時，不能跑出瀏覽器視窗外。若碰到邊緣需反彈或沿著邊緣滑動。

視覺/文案回饋（選配）：按鈕文字可動態改變，例如從「Click me!」變成「Catch me if you can!」或「Oops!」。

2.2 偷偷靠近模式

觸發條件：當滿足以下任一條件時觸發：

滑鼠游標靜止不動超過「忽略時間」（例如：2 秒）。

滑鼠游標距離按鈕非常遙遠，且持續一段時間沒有朝按鈕移動。

行為邏輯：

按鈕會以「極緩慢」且「不易察覺」的速度，朝目前滑鼠游標的座標直線移動。

如果移動過程中滑鼠突然動了，且進入「警戒距離」，則立即切換回「逃離模式」。

視覺/文案回饋（選配）：按鈕文字可變成「Hey...」、「Don't ignore me...」等。

2.3 點擊成功狀態

觸發條件：使用者透過極快的速度、或利用螢幕邊界死角，成功點擊到該按鈕。

行為邏輯：

跳出破關訊息（如彈出視窗 Alert 或網頁中央出現全螢幕恭喜動畫）。

按鈕可能顯示被擊敗的表情或文字（例如：「You got me!」），並停止移動。

3. 互動參數設定 

以下參數需保留彈性，以便在開發過程中進行微調以達到最佳手感：

參數名稱	建議初始值	說明


alert_distance (警戒距離)

	

100 - 150 px

	

滑鼠靠近到多近時，按鈕開始逃跑。




evasion_speed (逃跑速度)

	

快速 (Ease-out)

	

逃跑的初始速度，需比一般滑鼠移動稍快。




idle_threshold (靜止判定時間)

	

2000 ms (2秒)

	

滑鼠停留在畫面上不動多久後，按鈕開始靠近。




creep_speed (靠近速度)

	

1 - 2 px / 影格

	

按鈕偷偷靠近的移動速度（需極為緩慢）。

4. 介面與視覺設計

背景：極簡風格（純白或淺灰背景），確保使用者的視覺焦點完全集中在按鈕與游標上。

按鈕設計：

標準的按鈕外觀（圓角、陰影、顯眼的顏色如亮藍色或紅色）。

可加入 CSS 轉場效果，但在腳本控制位移時（如逃跑），建議使用 transform: translate() 搭配 requestAnimationFrame 以確保動畫平滑且不掉幀。

5. 技術規格

前端語言：HTML5, CSS3, Vanilla JavaScript (無需複雜的框架，原生 JS 即可高效完成)。

事件監聽：

mousemove：追蹤游標座標與計算距離。

click：判定按鈕是否被成功點擊。

mouseout / mouseleave：當游標離開視窗範圍時的處理（建議此時按鈕停留在原地等待）。

物理與數學運算：使用勾股定理計算兩點距離；使用二維向量計算逃跑與靠近的方向。

6. 未來可擴展項目

多按鈕模式：點擊成功後分裂成兩個按鈕。

音效回饋：逃跑時發出卡通滑稽音效，偷偷靠近時有微弱的腳步聲。

響應式設計 (RWD)：若要在手機版實作，需將「滑鼠靠近」的概念轉換為「手指觸控螢幕的座標與距離」。
